# BackgroundPanel control software

This software controls the backround panel featured in Platinenmacher streams.

# Functions
!led off -> Turns the LED off
!led rrr ggg bbb (r,g,b 0-255) -> Sets LED color to red, green, blue value
!led info|status -> Send position of LED in chat
!led run [blink|boom|rainbow|fastbow|morse|identify|stop] [Morse Text]
